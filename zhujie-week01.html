02

Process Work

Draft note Proposed process. No student sketches or Canva versions have been uploaded yet.

  1. Write and refine the personal motivation below. Count spaces and punctuation.
  2. Compare three homepage routes: a large wordmark, a poster-led composition, and an asymmetric collage. Draw the alternatives yourself.
  3. Test cherry wine text on cream, with pink used for emphasis. Keep navigation and dates stable while the expressive title can move.
  4. Build the selected route in Canva; capture a first draft and one meaningful revision.
  5. Translate the final idea into a working page and check both phone and desktop layouts.

Final Outcome

Motivation draft / 110 characters
I want to create eye-catching designs that inspire fresh ideas and reflect my playful, thoughtful personality.

04

Reflection

Draft note Reflection starter to rewrite after your actual work. This is not evidence of an activity already completed.

An expressive homepage still needs an obvious reading order. The useful question is whether visitors can remember the designer and find the work. After making the page, replace this starter with the specific layout decision that helped, the problem that remained, and the change made in response.

Hourly versus project-based

Hourly work charges agreed time; a fixed project fee depends on a clearly defined scope. This model allows one concept, two revision rounds and one digital poster size. Extra formats, printing and additional revisions need separate agreement.
